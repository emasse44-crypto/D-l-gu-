# Futsal Foot

Application de table de marque pour le futsal, distincte du projet Info-Delegue.

## Contenu
- `index.html` : version web de travail
- `android/` : projet Android Studio qui embarque l'application dans une WebView

## Android
Le projet cible Android 8.0 (API 26) minimum. Ouvrir le dossier `FutsalFoot/android` dans Android Studio puis utiliser **Build > Build APK(s)** pour produire l'APK.

**État :** source de travail, à tester avant utilisation officielle. Le dépôt ne contient pas d'APK compilé.
